# 📚 StudyTracker — AI-Ready Career Plan Tracker

A comprehensive study tracker for Jayasuriya's **TCS-to-Product-Company Career Plan (2026–2027)**.

## 🎯 Objective

Track a 52-week roadmap to become an **AI-augmented Software Engineer → Secure Product Engineer**, targeting ₹30–40 LPA product-company roles.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Storage**: Browser LocalStorage (no backend needed)
- **Charts**: Chart.js
- **Deployment**: GitHub Pages

## 📋 Features

- **Dashboard** — Current week, phase, overall progress
- **Weekly Planner** — Task tracking with checkboxes per week
- **Daily Schedule** — 14-hour/week breakdown across days
- **Milestone Tracker** — 6 bi-monthly milestone checkpoints
- **Statistics** — Charts for DSA problems solved, hours logged, skill progress
- **Notes & Journal** — Weekly reflections and learnings
- **Dark/Light Theme** — Eye-friendly modes

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/jayasuriya-it21/StudyTracker.git
   ```
2. Open `index.html` in your browser, or
3. Visit the GitHub Pages deployment
